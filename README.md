# Spider-Man: No Way Home - Movie Fan Website

## Project Overview

This project is a movie fan website based on Spider-Man: No Way Home (2021).

The website provides information about the movie, its characters, memorable scenes, ratings and reviews.

It was created as part of the Introduction to Information and Communication Technologies (ICT) course at FAST-NUCES Islamabad.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Website Pages

The website contains four pages:

### 1. Home (index.html)
- Introduction to Spider-Man: No Way Home.
- Favourite characters.
- Memorable movie scenes.
- Scene recommendation button.

### 2. Top Picks (toppicks.html)
- Top five favourite characters.
- Best movie moments.
- Memorable scenes and personal ratings.
- Favourite scene recommendation button.

### 3. Reviews (reviews.html)
- Personal movie review.
- Movie ratings.
- Audience opinions.
- Final movie verdict.

### 4. About (about.html)
- Information about the movie.
- Movie storyline.
- Main cast and characters.
- Purpose of the website.
- Information about the creator.

## Design and Features

- Dark navy blue background.
- Red and white colour scheme.
- Arial font.
- Consistent navigation bar across all pages.
- Tables for displaying information and ratings.
- Interactive JavaScript buttons.
- Shared CSS styling.
- Responsive navigation for smaller screens.

## How to Run the Website

1. Download or open the project folder.
2. Open the folder in Visual Studio Code.
3. Open index.html in a web browser.
4. Use the navigation bar to visit the other pages.

You can also use the Live Server extension in Visual Studio Code.
